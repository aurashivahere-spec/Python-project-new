# Security Policy

## Supported versions
Only the latest 0.x release receives fixes.

## Reporting a vulnerability
Do not open a public issue. Email the maintainers (see README) with steps to
reproduce. We aim to acknowledge reports within 72 hours.

## Scope
pqtrust stores key *fingerprints* and metadata only. It does not perform
signature verification itself; pair it with a verified cryptographic library.
